## 2. Сканим сеть
### nmap точки входа
Если дают точку входа ->
```bash
nmap -Pn -sV <адрес>

-Pn //(No Ping)Указывает Nmap пропустить этап обнаружения хоста.
-sV //(Service/Version Detection): Включает определение версий сервисов.
```
`Вместо того чтобы просто сообщить, что порт (например, 80) открыт, Nmap отправляет специальные запросы («зонды») и анализирует ответы (баннеры), чтобы узнать точное название программы и её версию (например, Apache 2.4.41).`

### точки входа нет
Если нет точки входа -> нужно сканить быстрым методом
```
nmap -sS -T4 <address> //Использует TCP SYN пакеты, быстро, не оставляет полных логов соединения.
nmap -sS -T5 <address> //Может пропустить порты
nmap -F <address> //Скан 100 самых популярных портов.
nmap -sn 192.168.1.0/24 //Скан сети, чтобы найти только включенные устройства

--max-rate 100 //Ограничивает отправку пакетов.
-n Отключает DNS-резолвинг (ускоряет работу, не определяя имена хостов).
```
